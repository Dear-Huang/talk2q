# Talk2Q — Talk to Quant

用自然语言写量化策略代码。

你用一句大白话说出交易想法，AI 一次只问一个关键问题，帮你把想法整理成“五格规则卡”；你确认规则后，它再生成目标量化平台的完整代码，并根据真实回测记录帮你核对和排错。

> 本项目不构成投资建议，不连接证券账户，不提供实盘下单。详见 [DISCLAIMER.md](DISCLAIMER.md)。

## 它做什么

1. **整理规则**：从“我想在沪深300里找市盈率低、利润增长的股票，每月换一次”这样的想法出发，补齐股票池、选股条件、买卖时点、仓位、风控等缺项。
2. **确认后出码**：规则卡确认后，生成聚宽、BigQuant、米筐等平台的策略代码，不暗改你的样本期、费率、阈值和仓位。
3. **回测排错**：依据平台真实报错、成交和持仓记录排查问题，区分“能运行”和“和你的规则一致”。
4. **平台迁移**：把已有策略反译成中文规则，再在另一平台重新生成，并逐项核对差异。

## 当前支持范围（v1.7）

| 平台 | 实测层级 |
|---|---|
| 聚宽 | 11 个“旧代码→中文→重新出码”往返案例真实云端回测；多数交易明细与原版一致，个别两侧同样失败或顺序不同 |
| BigQuant | AIStudio 0.1.11 日频策略真实完成并做账户算术核对；从聚宽迁移的结果与源平台不完全等价 |
| 米筐 | 仅开源 RQAlpha 6.4.2 合成数据测试；云端与 Plus 未实测 |
| 掘金 | 仅核验清单，无实测 |

已知限制：

- BigQuant 分钟级策略尚未跑通（历史成分池缺失、分钟数据权限受限）。
- 测试覆盖的是代码往返；“小白一句话 → 追问 → 规则卡 → 出码”的完整对话流程仍在补充验收。
- 任何新策略生成后都可能报错，须在平台实际运行并核对买卖两侧。不承诺零报错。

## 可选离线预检

```bash
python skills/huang-ai-quant-coach/scripts/check_strategy.py --platform joinquant 我的策略.py
```

只检查语法和有限的已知接口混用，不执行策略、不联网，不能代替平台回测。
