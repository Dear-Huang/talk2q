# 教学规则卡 / JQ-DEMO-1.2

用户于本轮确认按教学参数走查，用于教程截图及流程优化，不代表用户个人实盘策略。以下将工程选择明确写出，供教程演示复现。

| 编号 | 规则 |
|---|---|
| R1 从哪挑 | 上一交易日历史沪深300成分股，剔除该日停牌；下单时再查当日停牌及涨跌停。没有额外加入ST/行业/预测条件。 |
| R2 按什么挑 | 前一交易日PE>0且<20；最新已公告、从当年1月1日开始的累计净利润同比>0。原始财报表当期与同一公告的上年同期对比数配对，增长=(当期−上期)/abs(上期)，上期0/缺失跳过。PE升序、代码升序，最多10只。 |
| R3 买多少 | 虚拟10万元，每只调仓目标10%；不足10只不均分满仓。费用和整手可能造成轻微低配，受限残余按真实持仓处理。 |
| R4 什么时候卖 | 月调仓不在目标前10名则尝试退出。每个交易日15:30检查当日收盘价，严格低于平台持仓avg_cost的90%则加入次日待卖队列；avg_cost按平台动态复权处理；本例真实日志15.37元，与成交价相同，不包含另扣5元买佣。停牌/跌停/T+1卖不出则后续交易日重试，不伪造退出。止损后到下次月调仓才允许再买；当日止损执行优先，月调仓不当日回买。 |
| R5 多久看一次 | 自然月首个交易日09:31调仓，用上一交易日已知信息。每日09:31执行待卖，15:30检查止损。不是“设置每天盘后运行一次”包办交易。 |
| E1 环境 | 聚宽网页云端Python3，日频回测。回测调度的09:31在日频与模拟环境的行为以真实日志核对。 |
| E2 日期/基准 | 教学预设2024-01-02至2024-12-31；先做2024-01-02的字段探针。基准000300.XSHG。 |
| E3 费用 | 教学模型：买卖佣金各0.0003，最低5元；卖出印花税0.0005（本例2024年），PriceRelatedSlippage(0.002)，按平台说明为往返价差0.2%。非真实券商报价。 |
| E4 执行 | 先处理卖出，再按真实可用现金买入；费用预留。涨停买不到不以第11名替补，不在非月调仓补买，下一月再选。未成交残余保留。 |
| E5 数据/缺失 | 财报pub_date≤信号asof；最新报告按期末日和公告日排，使用同一公告中的当期/同期累计数，缺失跳过；不拿单季度indicator代替。 |
| E6 状态 | 2024年真实云端回测及抽样对账已完成；1.2加入不足一手先跳过。模拟已创建，开始2026-11-06，尚无真实定时执行证据。 |

单季度与累计口径区别已有真实探针：2024-01-02查看000001.XSHE，当时indicator同比为−2.22%，但同一已公告财报的累计净利润396.35亿元与366.59亿元相比为正增长。此例只解释数据口径，不是股票推荐。
