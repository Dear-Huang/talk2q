# BigQuant用户接入：代码放哪里、用户提供什么

核查日期：2026-11-09。此文前半依据官网公开说明；随后已进入真实登录的免费AIStudio，验证空白代码策略、文件上传菜单、Notebook打开、全部运行及真实历史回测。后续证据与完整交付要求见[云端实测](bigquant-complete.md)，用户当前界面仍优先。

## 先解决入口，再交付可运行文件

入口为官网导航“编写策略” → [AIStudio](https://bigquant.com/aistudio/)。AIStudio是网页版开发环境，左侧资源管理器，右侧编辑器；同时支持可视化策略与代码。数据平台、因子浏览页及“我的交易”不用于粘贴完整研究策略。

用户说“没看到贴代码的地方”时，先给入口并请其提供当前页面截图或网址，后续再补空白模板。不要要求小白先报SDK版本；也不要凭历史教程承诺其账号必有某个按钮。官网旧新手指南已明确标为旧版，不能作为当前菜单依据。

按实际界面分流：

| 用户看到的界面 | 代码如何落地 | AI应交付 |
|---|---|---|
| AIStudio尚未启动、资源选择或登录页 | 用户在官方页面登录/启动已有可用资源，再进入工作区 | 入口和下一步说明；不把登录页当代码编辑器 |
| 可视化模块连线图 | 沿用户当前官方模板适配；模块属性分别填SQL/参数，BigTrader事件函数编辑交易逻辑 | 修改后的完整模板/Notebook及改动位置；不能把整份Python塞进单个SQL框或K线函数框 |
| 已打开`.ipynb` Notebook | Python放代码单元格，SQL按模板放对应参数；运行所需的全部单元格 | 完整`.ipynb`及运行顺序，不只给一个回调函数 |
| AIStudio资源管理器、还没有策略文件 | 优先交付完整`.ipynb`，用工作目录的文件上传功能导入后打开；若文件被显示成源码，按当前界面选择Notebook编辑器 | 可上传文件及简短说明；具体菜单以用户截图为准 |
| 本地Python/VSCode | 用户在本机安装对应SDK并完成官方鉴权 | 完整`.py`、依赖版本和配置；此路线与云端模块模板分开 |

官方AIStudio说明支持“+”新建策略，缺少图标时可查“新建策略”插件，并说明“全部运行”。2026-09数据导入教程说明：左侧资源管理器中右键自己的工作目录 → “上传…”，且附`.ipynb`案例。后续真实工作区确认有“上传...”菜单，上传文件已出现；最终按字节传入的Notebook在工作区打开并“全部运行”成功。新建入口另有“空白代码策略”，名称会自动添加`.ipynb`。

## 用户最少提供什么

开始只需当前界面截图/网址和自然语言策略想法，按五格工作流一次补一个关键缺项。已有信息不重复索要。执行前补齐以下内容：

1. **环境依据**：当前官方空白模板或现有策略Notebook（隐去私有内容与凭证）。由AI识别`M.bigtrader.v30(...)`或`bigtrader.run(...)`入口、模块和依赖；用户不必懂这些名称。
2. **策略规则**：品种/范围、买卖条件、仓位、检查及调仓时间，按五格规则卡确认。指定因子时补全公式/口径、单位、信号日可得时点和组合方式，参见[因子工作流](factors.md)。
3. **回测设置**：样本起止、虚拟资金、频率、费率/滑点、成交时点。未知参数可建议，由用户确认后写入，不能暗改。
4. **可用条件**：账号能否进入AIStudio、所需数据是否有权限。先用已有资源和少量数据测试；遇到付费或权限提示再处理，不把买旗舰版列为普通网页用户的默认前提。
5. **自有因子才需要的材料**：授权可用的CSV/表结构、脱敏样本、字段单位、日期及证券代码格式、公告/可得时点。调用平台现成因子无需默认上传自有数据。

密码、验证码、Cookie和API密钥不进入聊天、Notebook或分发包。网页使用由用户官方登录；本地SDK鉴权由用户本机交互式配置。

## “直接服务”可做到哪一步

- **出码交付**：不需要用户交出账号；依据规则和当前模板生成适配的Notebook/完整代码，以及数据与运行说明。
- **协助云端运行**：需要用户已登录的AIStudio、可用计算资源和数据权限，并有浏览器/远程协作工具实际访问工作区。Skill本身是指导文件，不带官方云端执行连接器。运行后保留日志、委托/成交、持仓与现金对账，才报告相应验证层级。
- **本地SDK运行**：用户自行配置官方鉴权；Python和SDK版本、数据权限需核对。不能把项目本地6.0.3候选直接宣称云端模块可运行。本项目此前本地真实引擎因DAI日历缺API key停在业务回调前；后续云端0.1.11已完成真实数据回测与对账，不代表本地鉴权问题已解决。
- **本地IDE连接云端**：2026-10-23官方Connector文档说明SSH连接仅旗舰版会员可用，且须先启动AIStudio；这是独立选项，不是普通网页写代码的前提。
- **命令行提交云端**：本次查阅SDK与CLI文档均将AIStudio云端计算接口标为“暂未开放”。不能根据示例命令承诺`bq aistudio run`已经可用；未来以新官方文档和实际成功执行证据更新。

给小白的首轮说法示例：“打开官网的‘编写策略’，进入AIStudio。把现在的页面截图和你想做的策略告诉我，我先帮你确认入口，再做成能上传打开的策略文件。”截图作为正常对话附件提供，勿用仅支持文本的问答工具索要图片。
