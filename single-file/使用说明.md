# 开始使用

先用一句你自己的话描述策略，不需要先背术语。例：“我想在沪深300里找市盈率低、利润增长的股票，每月换一次。”这是演示想法，不是推荐买卖。

## 包里哪一个给谁用

| 文件 | 用途 |
|---|---|
| 黄同学_AI量化五格教练_v1.7.md | 单文件完整工作流，给DeepSeek等只能读文本的AI用 |
| huang-ai-quant-coach_v1.7.zip | Skill包，内含SKILL.md和按需读取的平台参考，给Claude Code、Codex、WorkBuddy导入 |
| Skill包内 assets/rule-card.md | 空白规则卡，自己先写清规则与待确认项 |

## DeepSeek：一个MD就能开始

1. 打开 https://chat.deepseek.com/ ，自行登录。
2. 新建对话，上传「黄同学_AI量化五格教练_v1.7.md」。如果当前界面不接收MD，打开文件，把全文复制到对话框发送；不要求安装软件或Skill。
3. 发送：

> 请按附件《黄同学AI量化五格教练》的工作流开始。我的方法是：在沪深300里找市盈率低、利润增长的股票，每月换一次。先别写代码，一次只问我一个问题。

4. 如果回答成了一长串问题，回复：“只保留当前最关键的一个问题，等我回答再问下一个。”
5. 规则确认后，再继续代码、报错或模拟盘阶段。新对话反译时只贴代码和环境信息，先不贴目标规则卡。

上传MD是把流程提供给当前对话，不等于永久安装到DeepSeek。新建对话、上下文太长或转给另一个AI时，应重新提供文件和当前确认版本。附件是否被完整读到，以实际回复为准。

## Claude Code / Codex：装成Skill

1. 解压「huang-ai-quant-coach_v1.7.zip」，得到`huang-ai-quant-coach`目录。
2. 放进技能目录：Claude Code为`~/.claude/skills/`，Codex为`~/.codex/skills/`。
3. 新开会话。Claude Code输入`/huang-ai-quant-coach`，Codex输入`$huang-ai-quant-coach`，再说出你的策略想法。

## WorkBuddy：导入Skill，重复使用

按2026-11-05查阅的[官方技能说明](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)：

1. 打开左侧“专家·技能·连接器”，选“技能”。
2. 点击“添加技能→上传技能”，选择「huang-ai-quant-coach_v1.7.zip」。上传的是单独技能包，不是整套资料压缩包。
3. 在“已安装”确认技能存在且已启用，然后新建一个任务。
4. 输入：“请用黄同学AI量化五格教练，帮我把下面的方法变成规则卡。先别写代码，一次只问一个问题。我的方法是：……”
5. 若当前版本无法导入，使用与DeepSeek相同的MD附件方式。不要为了教程修改全局安全/隐私设置。

本包不需要API密钥，不含自动下单脚本。对话、联网与文件处理是否消耗积分或需要特定权益，以你的账号为准。代码生成后仍须在量化平台实际运行。

## 平台适配已经包含什么

单文件MD内置聚宽、BigQuant等平台的关键代码契约和常见混用问题；Skill把平台说明拆成独立参考文件，附米筐适配、掘金核验清单和官方来源。先识别具体入口/版本，才写相应代码。

Skill另附`scripts/check_strategy.py`，会用Python的用户可自行做离线语法和有限混用检查：

```
python scripts/check_strategy.py --platform joinquant 我的策略.py
python scripts/check_strategy.py --platform bigquant --engine bigquant-cloud011 我的策略.py
```

第二行仅在确认是BigQuant AIStudio云端0.1.11时使用。脚本不执行策略、不联网，不能判断全部接口/数据权限或验证收益。DeepSeek网页不负责运行这个脚本；不会用Python也可以按MD流程在量化平台实际运行。
